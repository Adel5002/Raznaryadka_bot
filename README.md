# Бот «Мастер Разнарядок» (@raznaryadka_bot)

Мастера собирают разнарядку в Telegram Mini App и копируют её текст одной кнопкой.
Администратор получает пуш по каждой разнарядке и кнопкой «Свести разнарядки» получает Excel
в формате «Наряд и расстановка персонала».

## Запуск (Windows)

1. Дважды кликнуть `run.bat`. При первом запуске он сам поставит зависимости.
2. Бот поднимает веб-сервер на `localhost:8080` и **ngrok** (HTTPS-туннель, без него Telegram
   не откроет мини-апп), берёт его адрес и ставит кнопку меню «Разнарядка».
3. Написать боту `/start`.

Пока окно `run.bat` открыто, бот работает. Закрыть окно = остановить бота.
Бот запускается через «сторожа» (`python -m bot.supervisor`): если бот упал или завис —
сторож сам перезапустит его через несколько секунд.

**Фоном, без окна:** `start_bot_background.ps1` (логи — в `data\logs\`, см. «Логи и диагностика»):
```
powershell -NoProfile -ExecutionPolicy Bypass -File start_bot_background.ps1        # запустить
powershell -NoProfile -ExecutionPolicy Bypass -File start_bot_background.ps1 -Stop  # остановить
```
Не запускайте одновременно `run.bat` и фоновый запуск — два бота на одном токене мешают друг другу.

### ngrok
Бот берёт `tools\ngrok.exe`, если он есть, иначе системный ngrok. Бесплатный ngrok требует
свежую версию агента (сейчас минимум 3.28). Если в `data\logs\ngrok.log` ошибка `ERR_NGROK_121` —
выполните `tools\ngrok.exe update`.

### Чтобы адрес мини-аппа не менялся
Бесплатный ngrok при каждом запуске даёт новый адрес. Кнопка меню обновляется сама,
но у тех, у кого мини-апп был открыт, старый адрес отвечает 404 — приложение покажет
«Бот перезапускался — откройте заново» (черновик не теряется). Чтобы этого не было вовсе,
возьмите постоянный бесплатный домен:
dashboard.ngrok.com → Domains → «+ New Domain» → вписать его в `.env`:
```
NGROK_DOMAIN=ваше-имя.ngrok-free.app
```

### На сервере (VPS) с доменом
Поставить Python 3.11+, `pip install -r requirements.txt`, настроить nginx/Caddy с HTTPS
на `localhost:8080`, в `.env` указать `WEBAPP_URL=https://ваш-домен` и запускать
`python -m bot.supervisor` (или `python -m bot` systemd-сервисом с `Restart=always`).

## Настройки — файл `.env`
| Параметр | Что это |
|---|---|
| `BOT_TOKEN` | токен от @BotFather. Сменили токен — поменяйте здесь и перезапустите |
| `WEBAPP_URL` | готовый HTTPS-адрес мини-аппа (если пусто — берётся у ngrok) |
| `NGROK_DOMAIN` | постоянный домен ngrok |
| `USE_NGROK` | `0` — не запускать ngrok (если адрес задан в `WEBAPP_URL` или для проверки без мини-аппа) |
| `TZ_OFFSET_HOURS` | часовой пояс площадки (3 = МСК/Турция) — для «сегодня/завтра» |
| `EXCEL_SUFFIX` | хвост имени Excel-файла («общестрой СФЗ») |
| `FIXED_ITR` | постоянные ИТР, по умолчанию `Марьин М.И.:СМБ`; несколько — через `;` |

ID администратора зашит в `bot/config.py` (`ADMIN_ID = 5645916737`).

## Как это работает

**Мастер**
- `/start` → администратору приходит заявка с кнопками «Дать доступ / Отклонить».
- «Новая разнарядка»: дата по умолчанию — завтра (если завтра воскресенье — понедельник),
  прошедшую дату поставить нельзя. Имя мастера запоминается после первой разнарядки.
- Объект выбирается из шифров: `AKU.0911.91VTX.CSB.AS.TB0004` → **91VTX**.
  Под объектом сколько угодно планов, у каждого плана — работы (объём необязателен),
  техника (необязательно) и свой состав звена. Объектов — сколько угодно.
- Люди со статусом БС / Отпуск / Межвахта не ставятся в план, пока им не вернут «На работе»
  (прямо из окна выбора людей кнопкой «На работу»).
- **Выходной** — кнопка в окне выбора людей. Действует только на дату этой разнарядки (статус в штатке
  не меняется, при «Скопировать прошлую» не переносится). Человек убирается из плана, попадает в текст
  блоком «ВЫХОДНОЙ:», в Excel-«Расстановке» — «Выходной», водитель на выходном не считается в «Водителях».
- Переключатель «ИТР выходит на работу», необязательное примечание.
- «Скопировать прошлую» — берёт последнюю разнарядку, ставит новую дату, можно поправить.
- После отправки — «Скопировать текст» (или «Прислать в чат», чтобы переслать).
- Черновик сохраняется автоматически — сразу на телефон и на сервер (вверху: «✓ сохранено»).
- «🧹 Очистить» в карточке даты — убрать объекты, работы, людей и примечание и заполнить заново
  (дата, мастер и отметки БС/отпуск остаются). После смены даты приложение само предложит
  «Заполнить заново?». Есть «↩ Вернуть как было».
- Если правите уже отправленную разнарядку и меняете дату — предупредит, что она «переедет»,
  и предложит «Сделать новой» (старая останется).

**Администратор**
- Пуш «Гедаев У. сделал разнарядку на 12.11.2026» с текстом и кнопкой «📊 Свести разнарядки».
  Кнопка собирает **все** разнарядки на эту дату (хоть 2, хоть 10 мастеров) в Excel.
- Команда `/svod 12.11.2026` — свести за любую дату.
- В мини-аппе: Шифры (можно вставить пачкой), Штатка (ФИО, должность, статус; можно вставить
  столбцом из Excel), Сводка по дате, Доступ мастеров.

## Отказоустойчивость
- **Нет связи с Telegram** (обрыв, провайдер): сообщения бота (пуши, заявки, ответы) ложатся
  в очередь в базе и уходят, когда связь вернётся — даже если бот за это время перезапускался.
  Мини-апп при этом работает. Excel-сводку бот пробует отправить 4 раза, потом честно пишет,
  что связи нет.
- **Плохой интернет у мастера**: запросы повторяются сами; отправка разнарядки защищена от дублей
  (повтор не создаст вторую разнарядку и второй пуш админу). Черновик хранится на телефоне
  и досылается на сервер, когда связь появится; при сворачивании приложения — сразу.
- **Бот перезапустился / сменился адрес ngrok**: вместо «ошибка 404» — экран «Откройте заново»,
  черновик восстановится.
- **Бот упал или завис** — сторож перезапускает его. ngrok упал — бот поднимает его заново
  и обновляет кнопку меню.
- **Копия базы** — раз в сутки в `data\backups\` (хранятся 14 последних).

## Логи и диагностика
Что-то сломалось — пришлите разработчику (в чат с Claude) **архив логов**. Три способа:
1. Команда **`/logs`** в боте (только админ) — бот пришлёт `logs-razn-….zip`, его можно переслать.
2. Мини-апп → вкладка «Доступ» → «📦 Прислать логи в чат».
3. Бот не запускается — двойной клик по **`collect_logs.bat`**: архив появится на Рабочем столе.

Если Claude работает на этом же компьютере, архив не нужен — достаточно написать «посмотри логи».

Мастер может нажать **«🐞 Сообщить о проблеме»** в мини-аппе (внизу главной и редактора) и описать,
что случилось. Админу придёт уведомление с кнопкой «📦 Прислать логи», а вместе с описанием сохранится
журнал последних действий в приложении (что нажимал, что ответил сервер).

Если сервер ответил ошибкой, мастер видит **код** («Ошибка сервера (код a1b2c3)») — по нему
находится нужное место в логах.

Внутри архива и в папке `data\logs\`:
| Файл | Что там |
|---|---|
| `00_СВОДКА.txt` (только в архиве) | главное: ошибки за неделю (сгруппированы, с причиной), сообщения о проблемах |
| `system.txt` (только в архиве) | версия кода, настройки без секретов, состояние базы и очереди, копии базы |
| `errors.log` | только ошибки и предупреждения — с трассировками |
| `bot.log` | всё подряд: запуск, кто что сделал (разнарядки, статусы, доступ), сообщения Telegram |
| `access.log` | каждый запрос мини-аппа: пользователь, адрес, код ответа, время в мс |
| `supervisor.log` | перезапуски бота сторожем |
| `ngrok.log` | туннель |
| `reports\` | «Сообщить о проблеме»: описание + журнал действий на телефоне + черновик |

В каждой строке логов есть метка в скобках: `[a1b2c3]` — номер запроса мини-аппа, `[u123456]` —
номер сообщения Telegram. По ней находятся все строки одного действия. Токен бота в логи не пишется.
Логи сами ограничивают размер (старые части удаляются), старые логи из `data\` лежат в `data\logs\old\`.

## Excel-сводка
- **Наряд задание**: мастер → объект (сооружение, шифр) → работы; кол-во людей по каждому плану,
  ед. изм., объём, техника; внизу «Водители», «Количество ИТР» и «Количество монтажников».
  - ИТР = мастера, которые выходят, + постоянные ИТР (Марьин М.И., СМБ — параметр `FIXED_ITR`).
  - Водители = все из штатки с должностью «Водитель…» и статусом «На работе».
  - Монтажники = все из составов звеньев + водители (без двойного счёта).
- **Расстановка**: ИТР (первым — Марьин, СМБ) с их объектами, затем вся штатка: сначала водители
  (у них пишется должность — «Водитель»), потом остальные с объектом или статусом.
  Жёлтым — БС/Отпуск/Межвахта, оранжевым — «Не распределён» (на работе, но ни у кого в плане),
  тёмно-жёлтым — человек стоит у двух мастеров сразу.

## Сервер Fly.io
Бот может работать на Fly.io вместо этого компьютера — с постоянным адресом `https://raznaryadka.fly.dev`
(ngrok не нужен). Файлы: `Dockerfile`, `fly.toml`, `.dockerignore`.
- Одна машина shared-cpu-2x 1 ГБ (+512 МБ подкачки), Амстердам, всегда включена; диск 3 ГБ в `/app/data` (база, логи, копии).
- Токен — только в секретах Fly: `fly secrets set BOT_TOKEN=...` (в образ `.env` не попадает).
- Обновить код на сервере: `fly deploy --ha=false` из папки бота.
- Логи: `/logs` в боте, как и раньше; живой журнал — `fly logs`.
- **Одновременно бот может работать только в одном месте.** С 11.11.2026 бот работает на сервере, поэтому
  в `.env` на компьютере стоит `HOSTED_ON=https://raznaryadka.fly.dev`: `run.bat` и фоновый запуск
  откажутся стартовать и напишут почему. Вернуть бота на компьютер: `fly scale count 0 -a raznaryadka`
  (сервер остановится), затем удалить строку `HOSTED_ON` из `.env`.
- Команды (из папки бота; `fly` = `%USERPROFILE%\.flyinlyctl.exe`):
  `fly status` — состояние, `fly logs` — журнал вживую, `fly ssh console` — консоль сервера,
  `fly secrets set BOT_TOKEN=...` — новый токен (бот перезапустится сам).
- Копии: бот каждый день копирует базу в `data/backups/` (14 дней), Fly раз в сутки снимает копию
  всего диска (5 дней): `fly volumes snapshots list razn_data`.

**Замена базы** (перенос, восстановление из копии): положите файл как `data/import.sqlite3` и перезапустите бота.
При запуске бот проверит файл, сохранит прежнюю базу в `data/backups/before-import-….sqlite3` и подставит новую.
Негодный файл не подставляется — он переименовывается в `import-bad-….sqlite3`, ошибка пишется в `errors.log`.

## Импорт из старых Excel
```
.venv\Scripts\python -m bot.import_excel "путь\к\Наряд и расстановка ... .xlsx" [ещё файлы]
```
Шифры собираются со всех файлов, штатка — из самого свежего. Дубли не создаются.

## Файлы
- `bot/` — бот и API (aiogram 3 + aiohttp), `bot/excel.py` — сводка
- `webapp/` — мини-апп (HTML/CSS/JS без сборки)
- `data/bot.sqlite3` — база; ежедневные копии — `data/backups/`
- `data/logs/` — логи (см. выше), `collect_logs.bat` — архив логов на Рабочий стол
- `Dockerfile`, `fly.toml`, `.dockerignore` — сервер Fly.io (см. выше)
- `webapp/vendor/telegram-web-app.js` — своя копия скрипта Telegram (мини-апп откроется,
  даже если telegram.org недоступен)
